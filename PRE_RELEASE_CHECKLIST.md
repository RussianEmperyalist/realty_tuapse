# Pre-Release Checklist

Короткий чеклист перед выкладкой проекта на сервер.

## 1. Конфигурация

- [ ] В `APP_ENV` стоит `production`
- [ ] В `APP_DEBUG` стоит `false`
- [ ] В `APP_URL` указан реальный домен
- [ ] Настроена production БД `mysql`
- [ ] Настроен `MAIL_MAILER=smtp`
- [ ] Заполнены `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`
- [ ] Заполнены `REALTY_CONTACT_EMAIL` и `REALTY_SUPPORT_EMAIL`

## 2. Файлы и права

- [ ] Document root сервера указывает на `public/`
- [ ] Есть доступ на запись в `storage/`
- [ ] Есть доступ на запись в `bootstrap/cache/`
- [ ] Выполнен `php artisan storage:link`
- [ ] Установлено расширение `gd`, если нужны миниатюры для новых загрузок

## 3. Команды перед запуском

```bash
composer install --no-dev --optimize-autoloader
php artisan key:generate --force
php artisan migrate --force
php artisan optimize:clear
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

Если база пустая и нужен стартовый набор данных:

```bash
php artisan migrate --seed --force
```

Если нужен боевой администратор:

```bash
php artisan realty:create-user admin@example.com StrongPassword123 "Имя Пользователя" admin --employee=alexander-vladimirovich-shlyakhov
```

## 4. Почта

- [ ] Выполнен `php artisan realty:mail-test`
- [ ] Тестовое письмо реально пришло
- [ ] Проверена тестовая отправка из `/admin`

## 5. Медиа

- [ ] Выполнен `php artisan realty:media-audit`
- [ ] В отчете нет `MISSING`
- [ ] В отчете нет `BROKEN`

## 5.1. Бэкап базы данных (рекомендуется)

```bash
php artisan realty:backup-database
```

- [ ] Бэкап создан успешно
- [ ] Файл бэкапа в `storage/app/backups/`
- [ ] Размер файла разумный (>0 MB)

## 6. Smoke-check

Запустить:

```bash
php artisan realty:smoke-check
```

Или одним прогоном:

```bash
composer run preflight
```

Должны пройти:

- главная;
- контакты;
- поиск;
- новости;
- FAQ;
- статьи;
- формы;
- карточка объекта;
- legacy-редиректы;
- редирект с `/admin` на вход для неавторизованного пользователя.

## 7. Ручная проверка в браузере

- [ ] Главная открывается без сломанной верстки
- [ ] Карточки объектов показывают фото
- [ ] Поиск и фильтры работают
- [ ] Карточка объекта открывается корректно
- [ ] Сообщение по объекту отправляется
- [ ] Новости открываются
- [ ] Галерея открывается
- [ ] Контакты соответствуют согласованному списку
- [ ] На мобильном экране ничего не разваливается

## 7.1. SEO-проверка

- [ ] `/sitemap.xml` открывается и содержит валидный XML
- [ ] В sitemap есть объекты недвижимости
- [ ] В sitemap есть новости
- [ ] `robots.txt` доступен и разрешает индексацию

## 8. Админка

- [ ] Вход под администратором работает
- [ ] Вход под сотрудником работает
- [ ] Режим “администратор как сотрудник” работает
- [ ] Раздел `/admin/inquiries` открывается и показывает заявки
- [ ] CRUD объектов работает
- [ ] CRUD сотрудников работает
- [ ] CRUD новостей работает
- [ ] CRUD галереи работает
- [ ] Загрузка новых изображений работает

## 9. Безопасность и доступы

- [ ] Тестовые учетные записи заменены или отключены
- [ ] Пароли изменены на реальные
- [ ] `APP_DEBUG=false`
- [ ] Нет локальных тестовых SMTP-значений
- [ ] На сервер не попали лишние локальные файлы и логи

### 9.1. Проверка аутентификации

- [ ] Неактивный пользователь (is_active=false) не может войти
- [ ] При попытке входа неактивного — показывается сообщение "Учетная запись деактивирована"
- [ ] Rate limiting работает (6 попыток login, 3 попытки register)

## 10. После выкладки

- [ ] Проверить публичный сайт по реальному домену
- [ ] Проверить `/admin`
- [ ] Проверить `php artisan realty:media-audit`
- [ ] Проверить SMTP еще раз
- [ ] Проверить загрузку изображений
- [ ] Проверить старые SEO-критичные URL
