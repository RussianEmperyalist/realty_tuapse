## 1. Запуск проекта в Docker (для презентации)

### Требования

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Windows/Mac) или `docker` + `docker compose` (Linux)

### Быстрый старт

```bash
# 1. Клонировать или перейти в папку проекта
cd platform

# 2. Создать .env из шаблона для Docker
copy .env.docker .env

# 3. Собрать и запустить контейнеры
docker compose up -d --build

# 4. Сгенерировать ключ приложения
docker compose exec app php artisan key:generate

# 5. Выполнить миграции и наполнить БД демо-данными
docker compose exec app php artisan migrate --seed --force

# 6. Открыть сайт в браузере
start http://localhost:8080
```

Mailpit (перехват писем) будет доступен по адресу: [http://localhost:8025](http://localhost:8025)

### Полезные команды Docker

```bash
# Просмотр логов
docker compose logs -f app

# Остановка контейнеров
docker compose down

# Перезапуск
docker compose restart

# Запуск artisan-команд
docker compose exec app php artisan <команда>
```

## 2. Публичная часть сайта

### 2.1. Главная страница

**URL:** `/`

На главной странице отображаются:
- Шапка с логотипом агентства и контактными телефонами
- Навигационное меню (главные разделы сайта)
- Избранные объекты недвижимости (VIP / featured)
- Новости агентства (последние записи)
- Контактная информация в подвале (футере)
- Ссылки на все разделы сайта

---

### 2.2. Поиск объектов недвижимости

**URL:** `/search`

Полнофункциональный поиск с фильтрацией:

| Фильтр | Описание |
|--------|----------|
| **Тип сделки** | Аренда / Продажа |
| **Тип недвижимости** | Квартира, дом, комната, участок, новостройка, гостиница, гараж, коммерция |
| **Город / Район** | Туапсе / Туапсинский район |
| **Цена** | Диапазон (от — до) |
| **Комнат** | Количество комнат (1, 2, 3, 4+) |
| **Этаж** | Диапазон этажей |
| **Площадь** | Диапазон площади (м²) |
| **Избранные** | Только объекты с пометкой "избранный" / VIP |
| **Услуги** | Фильтр по доп. услугам |

Результаты поиска отображаются в виде карточек с:
- Фотографией объекта (обложка)
- Названием и адресом
- Ценой
- Количеством комнат, этажом, площадью
- Ссылкой на полную карточку объекта
- Кнопкой "В избранное"

Доступны три режима просмотра результатов:
- **Блочный** (сетка карточек) — по умолчанию
- **Табличный** (список с деталями)
- **На карте** (отображение на карте с метками)

---

### 2.3. Карточка объекта

**URL:** `/property/{slug}`

Полная информация о конкретном объекте недвижимости:

- **Фотогалерея** — слайдер изображений объекта с возможностью перелистывания
- **Основная информация:**
  - Название и адрес
  - Цена (с меткой и валютой)
  - Тип сделки (аренда / продажа)
  - Тип недвижимости
  - Количество комнат
  - Этаж / Этажность
  - Площадь (м²)
  - Окна (описание расположения окон)
- **Описание** — развёрнутое описание объекта
- **Дата публикации**
- **Контакты риелтора** — ФИО, фото, телефон, email сотрудника, ведущего объект
- **Карта** — местоположение объекта на карте (через координаты)
- **Форма "Сообщение по объекту"** — быстрая отправка запроса по этому объекту
- **Кнопка "В избранное"**

---

### 2.4. Новости

**URL:** `/news`

- Список новостей агентства (с пагинацией)
- Каждая новость содержит: заголовок, дату, изображение, анонс
- Полная новость: `/news/{slug}` — заголовок, изображение, полный текст, дата публикации

---

### 2.5. Фотогалерея

**URL:** `/informaciya/fotogalereya`

- Альбомы с фотографиями (недвижимость, город, мероприятия)
- Каждый альбом имеет обложку, название и описание
- Внутри альбома — сетка изображений с возможностью просмотра

---

### 2.6. Контакты и сотрудники

**URL:** `/contacts`

- Список всех сотрудников агентства (риелторов)
- Для каждого сотрудника: фото, ФИО, должность, телефон, email, краткое описание
- Карточка сотрудника: `/users/view?slug={slug}` — полная информация

---

### 2.7. Формы обратной связи

Все формы защищены от спама: **не более 5 отправок в минуту** (throttle).

#### Связаться с нами
**URL:** `/contact-us` (GET — форма, POST — отправка)

Поля: имя, email, телефон, сообщение.

#### Обратный звонок
**URL:** `/callback` (GET — форма, POST — отправка)

Поля: имя, телефон, удобное время для звонка.

#### Оставить заявку (бронирование)
**URL:** `/booking/request` (GET — форма, POST — отправка)

Поля: имя, email, телефон, сообщение, привязка к конкретному объекту.

#### Сообщение по объекту
**URL:** `/apartments/sendEmail` (GET — форма, POST — отправка)

Поля: имя, email, телефон, сообщение, объект (выбирается из списка).

После отправки любой формы:
1. Данные сохраняются в БД (в соответствующий журнал)
2. На email агентства приходит уведомление с деталями заявки
3. Пользователь видит сообщение об успешной отправке

### 2.9. Избранное

**URL:** `/favorites`

- Добавление объектов в избранное через кнопку на карточке
- Хранение избранного в `localStorage` браузера (не требует авторизации)
- Отдельная страница со списком избранных объектов
- Возможность удалить объект из избранного

---

### 2.10. Вход / Регистрация

**Вход:** `/login`

Поля: email, пароль, "запомнить меня".
После входа — редирект в админ-панель `/admin`.

**Заявка на регистрацию:** `/register`

Самостоятельной регистрации нет. Пользователь оставляет заявку:
- Имя, email, телефон (опционально), сообщение
- Заявка попадает администратору в журнал обращений
- Администратор связывается с пользователем и создаёт учётную запись

**Восстановление доступа:** `/recover`

- Запрос на восстановление, если пользователь забыл пароль
- Заявка отправляется администратору

**Выход:** `/logout`

## 3. Админ-панель

### 3.1. Вход в админ-панель

**URL:** `/login` → после успешного входа → `/admin`

Вход доступен пользователям с активной учётной записью. Если учётная запись деактивирована — вход блокируется с сообщением.

### 3.2. Дашборд

**URL:** `/admin`

Главная страница админ-панели содержит:

- **Статистика:**
  - Количество объектов недвижимости
  - Количество сотрудников
  - Количество новостей
  - Количество альбомов галереи
- **Последние 10 объектов** — быстрый просмотр недавно добавленных/изменённых объектов с указанием ответственного сотрудника
- **Фильтр по сотруднику** — для администраторов: просмотр объектов конкретного сотрудника
- **Режим сотрудника** (только для админа) — включение режима, при котором админ видит данные только выбранного сотрудника
- **Блок почты** — информация о текущем почтовом драйвере, возможность отправить тестовое письмо

### 3.3. Управление объектами недвижимости

**URL:** `/admin/properties`

#### Список объектов
- Таблица с пагинацией (20 объектов на страницу)
- Поиск по названию, адресу, legacy_id
- Фильтр по сотруднику
- Сортировка по дате публикации
- Для каждого объекта: заголовок, тип сделки, тип недвижимости, цена, статус (опубликован/нет)

#### Создание / Редактирование объекта

Форма содержит следующие поля:

| Поле | Описание |
|------|----------|
| **Название** | Обязательное, до 255 символов |
| **Slug** | ЧПУ-адрес, генерируется из названия, можно изменить вручную |
| **Legacy ID** | ID из старого сайта (для совместимости URL) |
| **Тип сделки** | Аренда / Продажа |
| **Тип недвижимости** | Квартира, дом, комната, участок, новостройка, гостиница, гараж, коммерция |
| **Город** | Туапсе / Туапсинский район |
| **Адрес** | Текстовое поле |
| **Цена** | Целое число |
| **Метка цены** | Дополнительный текст к цене |
| **Валюта** | руб., $, € |
| **Комнат** | Количество (0–50) |
| **Этаж** | Номер этажа (0–100) |
| **Этажность** | Всего этажей в доме (0–100) |
| **Площадь** | Число с двумя знаками после запятой |
| **Окна** | Описание расположения окон |
| **Описание** | Полный текст описания |
| **Координаты** | Широта и долгота (для отображения на карте) |
| **Телефон** | Переопределение контакта для конкретного объекта |
| **Опубликован** | Флаг: показывать на сайте или нет |
| **Избранный** | Флаг: VIP-объект (показывается на главной и в спецпредложениях) |
| **Дата публикации** | Когда объект был опубликован |
| **Сотрудник** | Ответственный риелтор |
| **Изображения** | Загрузка нескольких файлов (до 8 MB каждый). Автоматически создаются превью 820×428 |
| **Обложка** | Выбор главного фото среди загруженных |

#### Удаление объекта
- Каскадное удаление всех связанных изображений с диска

### 3.4. Управление сотрудниками

### 3.7. Журнал обращений

**URL:** `/admin/inquiries` (только admin)

Единый журнал всех входящих заявок с возможностью фильтрации по типу:

| Тип заявки | Источник | Отображаемые данные |
|------------|----------|-------------------|
| **Связаться с нами** | Форма `/contact-us` | Имя, email, телефон, сообщение |
| **Обратный звонок** | Форма `/callback` | Имя, телефон, сообщение |
| **Оставить заявку** | Форма `/booking/request` | Имя, email, телефон, сообщение, объект |
| **Сообщение по объекту** | Форма `/apartments/sendEmail` | Имя, email, телефон, сообщение, объект |
| **Регистрация** | Форма `/register` | Имя, email, телефон |
| **Восстановление доступа** | Форма `/recover` | Email, телефон |

Для каждой заявки отображается:
- Тип заявки (с русскоязычной меткой)
- Имя, email, телефон отправителя
- Текст сообщения
- Статус доставки уведомления на почту (pending / sent / failed)
- Ошибка доставки (если была)
- Дата создания

### 3.8. Тест почты (SMTP)

**URL:** На дашборде `/admin` — блок "Почтовая отправка"

- Ввод email-адреса получателя
- Отправка тестового письма
- При успехе: "Тестовое письмо отправлено"
- При ошибке: отображается причина неудачи

Доступна также CLI-команда:
```bash
php artisan realty:mail-test you@example.com
```

### 3.9. Ролевая модель

| Возможность | admin | employee |
|-------------|-------|----------|
| Дашборд со статистикой | Все объекты | Только свои |
| Объекты (CRUD) | Все | Только свои |
| Сотрудники (CRUD) | Да | Нет |
| Новости (CRUD) | Да | Нет |
| Галерея (CRUD) | Да | Нет |
| Журнал обращений | Да | Нет |
| Тест почты | Да | Нет |
| Режим сотрудника | Да | Нет |
| Создание пользователей | Через CLI | Нет |

**Режим сотрудника для админа:** администратор может включить фильтр "режим сотрудника" на дашборде и в списке объектов. В этом режиме админ видит только те объекты, которые принадлежат выбранному сотруднику — удобно для проверки работы конкретного риелтора.
